# التسجيل الأخير · The Last Recording

لعبة رعب نفسي وقصة بمنظور أول شخص للويندوز، داخل مول نيون مهجور، وكل شي تشوفه من خلال كاميرا تصوير قديمة (REC).

**تنزيل مباشر:** [LastRecording-Windows-Setup.exe](../../releases/latest/download/LastRecording-Windows-Setup.exe)

## التنزيل
روح لصفحة **[Releases](../../releases/latest)** ونزّل الملف المناسب لجهازك:

| الجهاز | الملف |
|---|---|
| ويندوز (تثبيت) | `LastRecording-Windows-Setup.exe` |
| ويندوز (بدون تثبيت) | `LastRecording-Windows-Portable.exe` |
| أي جهاز من المتصفح | `LastRecording-Browser.zip` ← فك الضغط وافتح `index.html` |

## التحكم
`W A S D` المشي · `Shift` ركض · الماوس للنظر · كلك يسار إطلاق · كلك يمين تصويب · `R` تعبئة · `F` الكشاف · `E` التقاط · `V` منظور ثالث · `T` دردشة · `Esc` إيقاف · `F11` ملء الشاشة

## التطوير
```
npm install
npm start        # تشغيل
npm run dist     # بناء ملف التثبيت
```
كل تحديث على `main` يعيد بناء ملفات التنزيل. رقم الإصدار في ملف `VERSION` بصيغة `00.00.01`.
